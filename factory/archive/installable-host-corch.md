## Installable host (`corch`)

The host becomes an app users install with `npm i -g corch` and start with `corch`, with no Bun, repo or `.env` needed: one compiled binary per platform (macOS and Linux, x64 and arm64) that holds all three parts, the host, the terminal daemon (`apps/ptyd-bun`) and the built local UI (`apps/web`), shipped as optional npm packages the way esbuild does. Once started it runs in the background, independent of the terminal that started it, and can be registered to start at login and restart after a crash, without ever ending the user's shells. The working name is `corch` (free on npm and Homebrew as of 2026-11-13). The repo's dev setup (`bun run dev`, the root `.env`, `apps/host/.data/`, the Vite UI) keeps working unchanged; only the packaged entry point has built-in defaults. The host stays local-only (SEC-1), so the installed binary always listens on 127.0.0.1 and that address is never a setting. The data folder is `~/.corch` on macOS and `$XDG_DATA_HOME/corch` on Linux, falling back to `~/.local/share/corch` when `XDG_DATA_HOME` is unset. Docs for the whole sprint come in its last job.
