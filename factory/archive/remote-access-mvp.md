## Remote access MVP

No accounts and no billing. The cloud server (`apps/server`) links each machine to the browser over one outbound WSS connection the machine opens. The server only relays traffic and routes on the frame envelope (machine id, frame type, request or channel id), never on paths, headers, bodies or statuses, so end-to-end encryption can be added later. The host checks a secret access key on every request, so the server never decides who gets in. The local app stays `apps/web`; the global app is a new `apps/client`, and both render the same page from `packages/terminal-ui`. See `docs/architecture.md`.
