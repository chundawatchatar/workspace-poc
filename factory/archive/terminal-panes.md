## Terminal panes

- [x] Terminal UI: mark the focused pane with a frame, so the active terminal is plain to see when a workspace is split. Today `PaneView` (`packages/terminal-ui/src/components/LayoutView.tsx`) only dims unfocused panes (`opacity-70` on the body) and draws the focused pane's active tab in `text-ink` with an accent icon. Give the focused pane a clear, rounded frame in a theme colour (an accent-tinted border or ring, `border-accent`/`ring-accent` at a strength that reads in every theme in `packages/ui/src/themes.ts`, light and dark), with a small gap between panes so each frame has room; unfocused panes keep a quiet `border-line` edge. Show it only when the workspace has more than one pane (a lone pane needs no marker), and keep the frame stable as focus moves (no layout shift: reserve the border width on every pane). It must not clash with the other overlays on a pane: the drop-target outline while a tab is dragged, the `zoom-frame` in full screen (a zoomed pane needs no focus frame) and the `attention-ring` (which stays on top and stays distinct). Keep the existing dimming unless the frame makes it redundant, and say which in the spec. No pane header or other new chrome; the tab bar stays as it is. Test that only the focused pane of a split workspace carries the frame (a `data-focused` attribute or role-level check, not class names), that a single pane and a zoomed pane don't, and that moving focus moves it. → 103-focused-pane-frame
