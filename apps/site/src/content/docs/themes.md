## Light, dark or system

The sun/moon button at the bottom of the sidebar switches between light and dark. **System** follows your operating system, and is the default.

## Choosing a theme

The palette button beside it, or `Ctrl+B T`, opens the theme picker. Each theme covers the interface and the terminal colours together.

| Dark | Light |
| --- | --- |
| Midnight (default) | Daylight (default) |
| Dracula | Solarized Light |
| Nord | Catppuccin Latte |
| Tokyo Night | |
| Gruvbox Dark | |

One theme is remembered for each side, so switching appearance uses the theme you chose for it.

> This site uses the same themes. Press `Ctrl+B T` to try them here.

## Motion

Panes glide when the layout changes, the sidebar slides, dialogs ease in and theme colours cross-fade. All of it switches off when your system asks for reduced motion.
